# Chant Sura / Fluelapass AOI Regression Fixture

This directory is a clean-checkout-safe regression fixture package.

It exists to exercise the AOI preparation and packaging workflow with compact
public-data-like metadata, a tiny terrain crop, and source/scenario records.
It is fixture-backed only and is not validation evidence, physical proof, or an
operational hazard product.

The frozen management AOI target summary lives at
`docs/chant_sura_fluelapass_management_aoi_acquisition_manifest.yaml`. It
fixes the LV95/LN02 bounds, the swissALTI3D tile id, the expected staging
roots, the ignored roots, and the read-only dry-run command sequence.
